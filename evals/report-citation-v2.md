# 引用准确率口径 v2 重算（2026-09-27）

评分器迭代（evals/scoring/citation_accuracy.py v2），四处修复：

1. **参考条目裸 URL 抽取**——"标题 - URL"纯文本条目（非 Markdown 链接）
   此前 url 字段为空，URL 从未参与比对，是基线 45.2% 的最大失配来源；
2. **URL 归一化增强**——percent-decode 统一（中文原文 vs percent-encoded
   形态属同一资源）、fragment 与跟踪参数（utm_* 等）剔除、scheme/host
   小写、查询参数排序；单侧无查询串退化 host+path 比对，两侧都带查询
   串必须全等（防 ?id=1 与 ?id=2 误合）；
3. **SQL 来源双路径**——表名命中条目文本即通过（模型写报告必然转述 SQL，
   原文包含几乎不可能命中）；未命中保留原文包含路径（兜底清单场景）；
4. **多条目短路 bug 修复**——同编号多条条目（闸门兜底清单按类型从 1
   重新编号）时，v1 在第一条失配后即放弃，后续条目的命中被漏掉。

同一批基线报告（baseline-w1）重新评分，不重跑 LLM：救回的是形式差异与
评分器自身缺陷，真失配（模型张冠李戴的引用）照旧扣分——w2-006 的
5 条错引保留未命中。
